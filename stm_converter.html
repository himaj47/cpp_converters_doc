generator.py

ROS2 Message and type adapter generator.

This module uses Jinja2 templates to generate:

  • msg files from parsed message specifications.

  • Type adapter C++ header files for custom message integration.

It transforms C++ struct definitions into ROS 2 message definitions and supporting adapter code.

main.py

CLI entry point for stm_converter.

This script converts C++ struct definitions into ROS2 msg message files and generate their corresponding type adapters and optionally message description YAML files.

It uses the Parser class to extract message definitions from C++ headers and the Generator class to produce ROS 2 artifacts based on Jinja2 templates.

Example:

`bash python3 main.py my_structs.hpp --namespace my_namespace --out-description msg_desc.yaml --out-msg msg/MyMessage.msg --out-adapter adapters/ --package my_ros_pkg --deps std_msgs sensor_msgs `

parser.py

Parser module for extracting ROS 2 message specifications from C++ structs/classes.

This module uses pygccxml to parse C++ header files and extract message definitions. It converts C++ types to ROS 2 message types, handles nested/non-primitive types, and returns ROS 2 compatible MessageSpecification objects.

class Parser(filename: str, pkg_name: str, namespace='', dependencies=None)[source]

Bases: object

Parses C++ header files into ROS 2 MessageSpecification objects.

This class:

  • Uses pygccxml to generate and parse Abstract Syntax Tree (XML representations) of C++ code.

  • Extracts C++ structs as ROS 2 messages.

  • Maps C++ primitive types to ROS 2 primitive types.

  • Resolves dependencies by checking existing/autogenerated ROS 2 message packages.

Attributes:

  • filename (str): Path to the C++ header file.

  • namespace (str): User namespace to parse. If empty, uses the last namespace found.

  • pkg_name (str): ROS package name for generated messages.

  • deps (list): list of dependent ROS packages.

  • ns: Parsed pygccxml namespace object.

  • user_ns (str): Name of the detected (last found) namespace if not provided.

  • struct_name (list[str]): List of struct names found.

  • msg_interfaces (dict): Mapping of package that generate interfaces -> available message interfaces from dependencies.

  • builtin_interface_pkgs (dict): Mapping of builtin packages that generate interfaces -> path to msg.

  • decls: Parsed pygccxml declarations.

  • global_namespace: Root pygccxml namespace object.

  • namespaces (list): All top-level namespaces in the file.

get_decls()[source]

Extract ROS 2 message specifications from parsed declarations.

This method:

  • Iterates over C++ structs in the target namespace.

  • Skips opaque types.

  • Converts C++ primitive types to ROS 2 primitives.

  • Processes user-defined types recursively.

  • Builds MessageSpecification objects for ROS 2 message and type adapter generation.

Returns:

list[MessageSpecification]: A list of message specifications objects

utils.py

Utility functions for parsing and generating ROS 2 messages.

This module provides helper functions to:

  • Convert struct or header names into ROS 2 message names.

  • Parse .msg files into field specifications.

  • Handle namespace-qualified types.

  • Identify primitive and non-primitive ROS 2 message field types.

  • Assist in message generation workflows for auto-generated ROS interfaces.

It integrates with rosidl_adapter to parse existing .msg files and handles recursive resolution of nested message fields.
