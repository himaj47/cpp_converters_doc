STM Converter Templates

These Jinja2 templates are used by stm_converter to generate ROS 2 message definitions and type adapters.

Message Template

This template defines how custom C++ structs are converted into ROS 2 message definitions.

message.txt
{%- for field_name, field_specs in msg.items() %}
{%- if field_specs[1] and field_specs[3] %}
{{- field_specs[3]}}/{{field_specs[0]}}[] {{field_name}}{{"\n"}}
{%- elif field_specs[1] %}
{{- field_specs[0]}}[] {{field_name}}{{"\n"}}
{%- elif field_specs[3] %}
{{- field_specs[3]}}/{{field_specs[0]}} {{field_name}}{{"\n"}}
{%- else %}
{{- field_specs[0]}} {{field_name}}{{"\n"}}
{%- endif %}
{%- endfor %}

Includes

Utility templates for managing include directives inside generated adapters.

  • extras.txt → Optional extra includes for non-primitive/autogenerated types.

  • includes.txt → Standard includes needed for adapters.

extras.txt
#include "{{pkg}}/type_adapters/{{header}}"
includes.txt
#pragma once
#include <rclcpp/type_adapter.hpp>
#include "{{interface_name}}/msg/{{struct_name}}.hpp"
#include "{{interface_name}}/headers/{{header}}.hpp"

{{extras}}

Array Types

These templates handle type adapter code when the field is of array/vector type.

  • adapter__to_custom.txt → Calls the adapter (convert_to_custom) of the non-primitive type inside the loop.

  • adapter__to_ros.txt → Calls the adapter (convert_to_ros_message) of the non-primitive type inside the loop.

  • loop.txt → Iterates through elements in array (source field).

  • np_push_back.txt → Pushes elements into destination field of non-primitive types.

  • push_back.txt → Pushes elements into destination field of primitive types.

adapter__to_custom.txt
{{namespace}}::{{struct}} element;
rclcpp::TypeAdapter<{{namespace}}::{{struct}}, {{pkg}}::msg::{{msg}}>::convert_to_custom(elem, element);
adapter__to_ros.txt
{{pkg}}::msg::{{msg}} element;
rclcpp::TypeAdapter<{{namespace}}::{{struct}}, {{pkg}}::msg::{{msg}}>::convert_to_ros_message(elem, element);
loop.txt
destination.{{field_name}}.clear();
destination.{{field_name}}.reserve(source.{{field_name}}.size());

for (const auto& elem : source.{{field_name}}) {
    {{content}}
}
np_push_back.txt
destination.{{field_name}}.push_back(element);
push_back.txt
destination.{{field_name}}.push_back(elem);

Non-Array Types

These templates handle type adapter code when the field is a non-array type.

  • na_adapter__to_custom.txt → Calls the adapter (convert_to_custom) of the non-primitive type.

  • na_adapter__to_ros.txt → Calls the adapter (convert_to_ros_message) of the non-primitive type.

  • non_array_types.txt → Direct field assignment for non-array types.

na_adapter__to_custom.txt
rclcpp::TypeAdapter<{{namespace}}::{{struct}}, {{pkg}}::msg::{{msg}}>::convert_to_custom(source.{{field_name}}, destination.{{field_name}});
na_adapter__to_ros.txt
rclcpp::TypeAdapter<{{namespace}}::{{struct}}, {{pkg}}::msg::{{msg}}>::convert_to_ros_message(source.{{field_name}}, destination.{{field_name}});
non_array_types.txt
destination.{{field_name}} = source.{{field_name}};
